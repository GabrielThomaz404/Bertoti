Texto 1 - Atividade 1

A engenharia de software  não é rigorosa comparada a outros tipos de engenharia, apesar disso temos que olhar de forma confiante conforme o tempo for passando, justamente por se tornar cada vez mais frequente no cotidiano. Com a crescente dependência da tecnologia, adotar esses métodos e práticas torna-se essencial, para garantir maior qualidade, segurança e confiabilidade durante o desenvolvimento dos sistemas.

Texto 2 - Atividade 2

Mostra que a engenharia de software não é apenas programar, mas também envolve outros aspectos que precisam de atenção durante o desenvolvimento, para que ele continue útil e que pode ser modificado ao longo do tempo.
