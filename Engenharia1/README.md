Atividade 3 - Trade-off

Custo vs. desempenho: um computador barato pode ter desempenho inferior.
Velocidade vs. memória: um programa fica mais rápido, mas consome mais RAM.
Automatização vs. controle: automatizar processos economiza tempo, mas reduz algumas intervenções manuais.
